Personal Project

Multi-agent systems
Multi-Agent Codebase Intelligence System
Python
Anthropic API
Qdrant

A distributed codebase is hard to hold in one head. This system holds it instead: the source of every microservice is indexed into a Qdrant vector database for semantic retrieval across service boundaries.

Ask it a question in plain language and an orchestrator agent spawns seven to eight parallel sub-agents, each searching the vector store iteratively until it has the full picture of its slice of the code. Their summaries flow back to the orchestrator, which composes a grounded answer — and asks the user a clarifying question when it hits genuine ambiguity rather than guessing.

query ──▶ orchestrator ──▶ 7–8 sub-agents (parallel) │ iterative search · Qdrant │ ◀────── code summaries grounded answer ◀──┘ or: clarifying question → user

In practice it earns its keep grooming PRDs, generating Jira tasks, and producing technical documentation straight from the live codebase instead of stale wikis.
